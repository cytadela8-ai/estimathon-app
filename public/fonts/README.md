# Local typeface

Bricolage Grotesque, by Mathieu Triay, is distributed under the SIL Open Font License
in [OFL.txt](OFL.txt). The Latin and Latin Extended WOFF2 subsets include Polish glyphs.
They contain variable weights 400–800 and optical sizes 12–96.

Source: Google Fonts, `bricolagegrotesque` version 9, downloaded 2026-10-29 using the
Google Fonts CSS endpoint for `Bricolage Grotesque:opsz,wght@12..96,400..800`.
Upstream: https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque

The browser loads both subsets from this server. No connection to Google Fonts is made
when using the application.
